Step 22.42 — совместимость с оптимизирующими модами, seller 800ms, talisman-атрибуты

База: Step 22.41.

Изменения:
1) Убрано автоматическое включение PotatoMode при автобае/продаже.
   .potatomode теперь включается только вручную.
   AutomationPerformance остаётся активным, чтобы отключать тяжёлые визуальные подсказки во время автоматизации.

2) Seller задержка изменена на 800ms:
   MalfixTimings.AUTOSELL_SELL_MS = 800L

3) Продажа из main inventory переделана ближе к старому SpookyBuy:
   вместо SWAP в пустой hotbar + выбор слота используется pickFromInventory / method_2916.
   Это должно уменьшить лаг в момент, когда seller берёт предмет в руку.

4) Убрано требование пустого hotbar-слота для продажи предметов из основного инвентаря.

5) Талисманы теперь различаются как в старом автобае — по AttributeModifiers.
   Для талисманов больше недостаточно просто совпадения названия/слова "талисман".
   Поддержаны сигнатуры: Крушителя, Карателя, Раздора, Тирана, Ярости, Скорости, Дедала.

6) Для совместимости с Sodium/Lithium/FerriteCore mixin config сделан мягким:
   required=false, defaultRequire=0.
   Это снижает шанс краша, если Sodium меняет render methods, нужные только для PotatoMode.

Можно ставить вместе с:
- sodium-fabric-mc1.16.5-0.2.0+build.4
- lithium-fabric-mc1.16.5-0.6.6
- ferritecore-2.1.1-fabric

Важно:
- OptiFabric вместе с Sodium/Lithium использовать нельзя.
- Если .potatomode вручную включён на Sodium и часть мира не скрывается — это нормально, главное что запуск не должен падать.
