Step 22.26 — полный перенос цепочки расстака из старого SpookyBuy

Что исправлено:
1) Расстак теперь запускается как в старом .jar не сразу, а через фазу подготовки:
   - закрыть контейнер/GUI, если он открыт;
   - подождать примерно 1500ms;
   - только после этого кликать player inventory handler syncId=0.

2) Seller-loop больше не останавливается из-за блокирующего GUI, если перед продажей есть предметы для расстака.
   Сначала он пытается выполнить old-Spooky unstack phase, потом уже переходит к продаже.

3) Добавлен fallback-match для расстака:
   - строгий matcher остаётся первым;
   - если он не смог сопоставить кастомный предмет по NBT/чарам, расстак пробует безопасное совпадение по itemId + имени/tooltip/NBT;
   - fallback работает только для предметов, где в GUI явно включено "Расстакивать".

Команды проверки:
.mab unstack status
.mab unstack once
.mab sellcycle 10 300
.mab cyclefull

Важные статусы:
needs=false — предмет не распознан как цель с включённым "Расстакивать".
canNow=false — нет пустого слота под отделённый стак.
seller-loop preparing old unstack — новая подготовительная фаза работает.
seller-loop old unstack tick — были отправлены клики расстака.
