Step 22.41 — откат прямого seller-пакета + продажа перед автобаем

База: Step 22.40.

Что изменено:
1) Откат Step 22.40 для /ah sell:
   - больше не используется прямой ChatMessageC2SPacket для команды продажи;
   - seller снова отправляет /ah sell через обычный client.player.sendChatMessage(command), ближе к старому SpookyBuy;
   - это нужно, потому что прямой пакет при 400ms мог фризить клиент и вызывать spam-kick.

2) Seller теперь работает безопаснее:
   - базовая задержка продажи возвращена к старому Spooky-ритму: 1200ms;
   - seller не отправляет следующий /ah sell, пока ждёт ответ сервера о прошлой продаже;
   - если ответа нет, есть безопасный timeout 2500ms, после которого seller продолжит без спама.

3) Перед full-auto автобаем теперь идёт продажа:
   - после Anti-AFK fullauto сначала открывает /ah;
   - заходит в хранилище;
   - забирает предметы по старой one-by-one storage-drain логике;
   - закрывает GUI и продаёт;
   - только после этого запускает buy/refresh фазу.

Сохранено:
- SellOnly каждые 30 секунд;
- сбор хранилища по одному предмету;
- расстакивание 350ms;
- NO_MONEY guard;
- closeHandledScreen fix для расстака;
- old Spooky refresh click;
- PotatoMode/low-lag режим.
