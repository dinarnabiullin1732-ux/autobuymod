Malfix AutoBuy Step 17 — Real seller, hand-only safe mode

Добавлено:
.mab sellreal
.mab sellnow
.mab realsell

Что делает:
1. Сканирует инвентарь как selltest.
2. Берёт цену продажи только из нижнего поля GUI.
3. Если нижняя цена продажи = 0, продажа блокируется.
4. Проверяет, что предмет уже выбран в руке:
   handPlan = READY_IN_HAND
   selectedHandMatches = true
5. Проверяет, что автобай/покупка/loop сейчас не активны.
6. Проверяет, что нет открытого GUI кроме чата.
7. Отправляет:
   /ah sell <sellUnitPrice * count>

Важно:
- Предметы из основного инвентаря пока НЕ перемещает.
- Реальная продажа работает только когда нужный предмет уже в руке/выбранном хотбар-слоте.
- Это специально сделано безопасно, чтобы не продавать случайный предмет.

Проверка:
1. В GUI выставь нижнюю цену продажи больше 0.
2. Возьми нужный предмет в руку.
3. Напиши:
   .mab selltest
4. Убедись:
   handPlan=READY_IN_HAND
   totalPrice правильный
5. Потом:
   .mab sellreal
