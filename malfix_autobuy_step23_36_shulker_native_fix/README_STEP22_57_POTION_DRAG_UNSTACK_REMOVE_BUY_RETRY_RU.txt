Step 22.57 — Potion drag-unstack + remove same-slot buy retry

Основа: Step 22.56.

1) Убрана система повторного клика покупки по тому же лоту.
   В Step 22.54 была добавлена попытка повторно нажать buy, если тот же lot всё ещё виден
   в том же слоте аукциона. На целевом сервере это не помогло, поэтому retry полностью удалён
   из ControlledBuyClickExecutor. Теперь real buy снова делает один валидированный Ctrl+LMB click
   и ждёт chat/fingerprint result без дополнительных повторных кликов.

2) Для "Несоздаваемое зелье" добавлен отдельный способ расстака через LMB drag distribution.
   Обычный старый способ: pickup stack -> right click empty slot N times -> return remainder.
   На этом сервере он ограничивается именно для зелий.

   Новый способ только для minecraft:potion target "Несоздаваемое зелье":
   - берёт весь стак зелья на курсор;
   - отправляет vanilla QUICK_CRAFT left-drag sequence;
   - распределяет стак по нескольким слотам, как ручное зажатие ЛКМ по слотам;
   - источник включается в список drag slots, поэтому стак распределяется обратно и в исходный слот;
   - если что-то осталось на курсоре, есть safety return без выброса предметов.

3) Для этого зелья поле GUI "количество расстака" теперь означает количество слотов для drag.
   Примеры:
   - 8 => стак 64 примерно раскладывается на 8 слотов по 8;
   - 16 => стак 64 примерно раскладывается на 16 слотов по 4;
   - 5/6 => рабочий режим для мягкого распределения без зависимости от размера исходного стака.

   Default для нового/старого конфига выставлен на 6, если у "Несоздаваемое зелье" стояло 1.

Не тронуто:
- обычный right-click unstack для остальных предметов;
- effect-based matcher зелья из Step 22.56;
- refresh old-Spooky style;
- storage drain fix.
