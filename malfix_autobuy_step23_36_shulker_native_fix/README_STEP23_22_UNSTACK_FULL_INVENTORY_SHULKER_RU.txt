Фикс зависания при расстакивании:
- если во время old-Spooky-style расстакивания инвентарь забился до 0 свободных слотов, native shulker storage теперь получает приоритет выше seller/unstack loop;
- seller/unstack prepare сбрасывается перед открытием шалкера, чтобы цикл не зависал на ожидании пустого слота;
- после перекладывания в шалкер продажа/расстакивание продолжают переоценивать инвентарь;
- /ah не восстанавливается автоматически для emergency из sell/unstack фазы, чтобы seller-loop не остановился из-за открытого аукциона.

После обновления: .mab scripts reload и .mab shulker reset.
