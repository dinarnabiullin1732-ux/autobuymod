Malfix AutoBuy Step 17.3 — Seller: main inventory -> empty hotbar -> sell

Что добавлено:
.mab sellreal теперь умеет продавать предмет из основного инвентаря, но только если в хотбаре есть свободный слот.

Логика:
1. READY_IN_HAND:
   - сразу /ah sell.
2. CAN_SELECT_HOTBAR:
   - выбирает слот хотбара;
   - проверяет READY_IN_HAND;
   - отправляет /ah sell.
3. NEEDS_MOVE_TO_HOTBAR_FROM_SLOT:
   - ищет пустой слот хотбара;
   - если пустого нет, блокирует продажу;
   - SWAP-кликом перекладывает предмет из основного инвентаря в пустой слот хотбара;
   - выбирает этот слот;
   - проверяет READY_IN_HAND;
   - отправляет /ah sell.

Безопасность:
- если хотбар полностью занят, предметы не заменяются;
- чужие предметы из хотбара не трогаются;
- цена продажи берётся только из нижнего поля GUI;
- sellPrice=0 не продаётся.

Проверка:
1. Поставь нижнюю цену продажи в GUI.
2. Убери предмет в основной инвентарь.
3. Оставь хотя бы 1 пустой слот в хотбаре.
4. Напиши .mab selltest.
   Должно быть:
   handPlan=NEEDS_MOVE_TO_HOTBAR_FROM_SLOT_<slot>
5. Напиши .mab sellreal.
   Должно переложить предмет в хотбар, выбрать его и отправить /ah sell.
