Step23.15 — shalk.js task fix

Проблема step23.14:
- guard закрывал /ah до того, как старый shalk.js успевал заполнить shulkerSlots/currentMode;
- после закрытия /ah state переходил в WAIT_SCREEN_CLOSE, но список shulkerSlots оставался пустым, поэтому openCurrentShulker() сразу завершал задачу и возвращал автобай.

Исправление:
- guard перенесён внутрь startShulkerSequence/startEcSequence после штатной инициализации скрипта и pauseAutoBuy();
- теперь при полном инвентаре скрипт сначала находит шалкер в хотбаре, сохраняет currentMode, ставит автобай на паузу, закрывает /ah, затем открывает шалкер и перекладывает слоты.

Важно:
- shalk.js работает только с шалкерами в хотбаре; шалкеры в основном инвентаре он не ищет.
- после обновления нужен .mab scripts reload или перезапуск клиента.
