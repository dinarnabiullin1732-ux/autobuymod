Быстрая сборка без постоянного скачивания Gradle

Главный файл:
00_FAST_BUILD_NO_REDOWLOAD.cmd

Что изменено:
1. Gradle больше не скачивается в папку каждого нового проекта.
2. Gradle ставится один раз в:
   C:\Users\1\.malfix_tools\gradle-8.14
   или в аналогичную папку твоего пользователя.
3. В новых версиях проекта этот же Gradle будет использоваться повторно.
4. Окно PowerShell больше не должно долго висеть на строке "Запись веб-потока", потому что прогресс скачивания отключен.

Первый запуск всё равно может занять время:
- Gradle скачивается один раз.
- Minecraft, Loom и Yarn-зависимости тоже скачиваются Gradle-кэшем.

Следующие сборки должны быть быстрее:
- запускай 00_FAST_BUILD_NO_REDOWLOAD.cmd
- если нужно полностью пересобрать, запускай 01_CLEAN_BUILD_NO_REDOWLOAD.cmd

Если Java 21 лежит не тут:
C:\Program Files\Java\jdk-21

открой .cmd файл и замени строку:
set "JAVA_HOME=C:\Program Files\Java\jdk-21"
на свой путь к JDK 21.
