Step 21.2 — /ah search cheapest marker optimization

Изменения:
1. Подсветка самого дешевого лота теперь работает только после команды /ah search <название>.
2. В обычном /ah подсветка отключена полностью.
3. Убрана зелёная рамка: теперь используется лёгкий зелёный фон слота + маленькая нижняя метка.
4. Уменьшены лаги: скан tooltip/цен не выполняется на каждый drawSlot, а кэшируется и обновляется примерно раз в 350ms, только в /ah search.
5. Слот-хранилище и последняя управляющая строка по-прежнему не считаются предметами для подсветки.

Как проверить:
/ah — подсветки быть не должно.
/ah search порох — самый дешевый лот на текущей странице должен получить зеленоватый фон.
Если фон не появляется, значит цена в tooltip не распознана — нужен скрин tooltip конкретного лота.
