Step23.18

Исправлен автозапуск шалкер-склада.

Симптом:
- .mab shulker test открывает шалкер, значит right-click/open работает;
- но при полном инвентаре во время автобая автоматический перенос не стартует.

Причина:
- автоматический триггер мог блокироваться состоянием ожидания результата покупки, legacy JS pause или состоянием runtime, пока открыт /ah.

Что изменено:
- если инвентарь реально полный, есть шалкер в хотбаре и открыт /ah или экран закрыт, native shulker task получает приоритет и стартует принудительно;
- при старте native task сбрасывается зависшая legacy script pause;
- seller/storage фазы всё ещё защищены от вмешательства шалкера.

Проверка:
1. положить шалкер в хотбар;
2. включить автобай;
3. дождаться полного инвентаря;
4. /ah должен закрыться один раз, открыться шалкер, предметы должны переложиться.

Диагностика:
.mab shulker status
