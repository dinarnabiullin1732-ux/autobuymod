Step 22.59 — potion drag-unstack min source count + GUI field

Что исправлено:
- После Step 22.58 зелья корректно расстакивались до конца, но после обработки всех крупных стаков бот снова начинал трогать уже разложенные маленькие стопки.
- Причина: для potion drag-unstack проверка была слишком широкой: любой стак зелья count > 1 снова считался кандидатом.

Что изменено:
1) Добавлен порог potionDragMinSourceCount.
   Для drag-зелий источник берётся в работу только если stack.count >= potionDragMinSourceCount.
   По умолчанию: 24.

   Пример:
   - 64, 48, 32, 24 — будут расстакиваться;
   - 16, 11, 8 — будут считаться уже разложенными и не будут трогаться повторно.

2) В GUI предметов добавлено поле "Мин. стак".
   Оно отображается для drag-зелья "Несоздаваемое зелье".
   Это поле отвечает именно за минимальный размер исходного стака, с которого бот начинает drag-unstack.

3) Поле сохраняется в config/malfix-autobuy.json как:
   "potionDragMinSourceCount": 24

4) Старая логика staged drag из Step 22.58 сохранена:
   pickup -> QUICK_CRAFT start -> по одному slot каждые ~70ms -> QUICK_CRAFT end -> recovery остатка курсора.

Важно:
- Поле "Расстак/кол-во" для этого зелья по-прежнему означает количество drag-slots.
- Новое поле "Мин. стак" означает минимальный размер исходного стака, который бот вообще будет трогать.
- Если поставить "Мин. стак" слишком низко, например 2 или 8, бот снова может начать повторно расстакивать уже разложенные стопки.
- Рекомендуемое значение: 24. Если после drag остаются стопки по 16 и их не надо трогать — 24 подходит.
