Malfix AutoBuy Step 16.3 — GUI предметов с раскрытием настроек

Что изменено:
1. При клике по предмету раскрываются дополнительные настройки прямо в списке.
2. Верхнее поле — цена покупки.
3. Нижнее поле — цена продажи.
4. Добавлен переключатель "Расстакивать".
5. Добавлено поле "Кол-во" для расстака.
6. Все изменения сохраняются сразу.
7. Seller теперь сначала берет sellUnitPrice из GUI предмета.
   Если sellUnitPrice не задан, остается старый fallback через markup.

Как проверить:
- Открой GUI
- Нажми на предмет
- Введи цену покупки сверху
- Введи цену продажи снизу
- При необходимости включи расстак и укажи количество
- Закрой GUI
- Используй .mab selltest

Ожидаемо:
- Покупка и продажа разделены
- По предмету виден отдельный блок настроек
- Конфиг сохраняет поля sellUnitPrice, unstack, unstackAmount
