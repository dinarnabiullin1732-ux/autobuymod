STEP 20 — Parser + Anti-AFK

Что добавлено:

1. Анти-АФК / реконнект как в старом автобае, но безопаснее для текущей архитектуры:
   - по умолчанию включён;
   - интервал: 240000 ms / 4 минуты;
   - команда: /hub -> пауза 2000 ms -> /an<анархия> -> пауза 3000 ms -> /ah;
   - запускается только в безопасный момент между фазами full-auto, а не во время клика покупки/продажи/хранилища;
   - если анархия не определилась автоматически, можно задать вручную.

Команды анти-АФК:
   .mab antiafk status
   .mab antiafk on
   .mab antiafk off
   .mab antiafk interval 240000
   .mab antiafk anarchy 505
   .mab antiafk anarchy auto
   .mab antiafk test

2. Парсер цен по процентам:
   - открывает /ah search <название предмета>;
   - ждёт открытие аукциона;
   - берёт минимальную цену за штуку на текущей странице;
   - выставляет цену покупки = минималка * buyPercent / 100;
   - выставляет цену продажи = минималка * sellPercent / 100;
   - дефолт: покупка 80%, продажа 90%;
   - сохраняет цены в config после обновления.

Команды парсера:
   .mab parser
   .mab parseall
   .mab parse "Название предмета"
   .mab parserstop
   .mab set parserBuy 80
   .mab set parserSell 90
   .mab set parserWait 650

3. GUI парсера:
   - в главном GUI добавлена кнопка "Парсер" рядом с "Бинды";
   - в отдельном окне можно поставить:
     - Покупка %;
     - Продажа %;
     - ожидание после /ah search;
   - кнопка "Парсить все" запускает парсер всех предметов.

Важно:
   - Парсер не запускается, пока работает full-auto/seller/buy-loop, чтобы не сбивать основной цикл.
   - Анти-АФК не вмешивается во время покупки, продажи и работы с хранилищем.
   - .mab stop теперь также останавливает full-auto timed, парсер и текущий anti-AFK.
