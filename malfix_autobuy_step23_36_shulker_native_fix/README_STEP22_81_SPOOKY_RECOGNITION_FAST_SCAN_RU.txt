STEP 22.81 — Spooky-style распознавание сфер/талисманов + ускоренный скан

Что исправлено:
1) Сферы больше НЕ считаются оригинальными только по названию.
   Раньше правила вида "texture_hash||сфера титана" могли пропустить фейк, если игрок просто переименовал голову в "Сфера Титана".
   Теперь для сфер требуется сильный идентификатор: skull texture hash/base64/SkullOwner textures или серверный tag вида attribute-item-* / sphere-item.

2) Старые правила каталога для сфер переписаны на строгие:
   - Сфера Хаоса: texture hash
   - Сфера Сатира: texture hash
   - Сфера Бестии: texture hash
   - Сфера Ареса: texture hash
   - Сфера Гидры: texture hash
   - Сфера Титана: texture hash
   - Сфера Афины: attribute-item-safina

3) Для талисманов сигнатура теперь ищется не только в label, но и в contains/tag.
   Это нужно, если label английский, а русское имя талисмана лежит в другом поле цели.

4) Скан ускорен через индекс целей по itemId.
   Раньше каждый слот мог прогоняться по всему списку целей. Теперь сначала берутся только цели с тем же itemId плюс цели без itemId.
   Это снижает лишние сравнения и должно быстрее доходить до покупки.

Изменённые основные файлы:
- src/main/java/ru/malfix/autobuy/config/ScriptItemCatalog.java
- src/main/java/ru/malfix/autobuy/scanner/ItemMatcher.java
- src/main/java/ru/malfix/autobuy/scanner/AuctionScanner.java

Проверка:
- Частичная компиляция scanner-related Java классов через javac прошла успешно.
- Полный Fabric/Gradle build в этой среде не запускался, потому что в архиве нет gradlew и здесь нет локального gradle.

Как собрать:
- На Windows используй существующий скрипт проекта: 00_FAST_BUILD_PORTABLE_JDK21.cmd или 01_BUILD_MOD.cmd.
- Если у тебя уже есть старый сохранённый конфиг целей, проверь, что у сфер не осталось правил вида "hash||название". Каталог должен попытаться пропатчить их сам, но лучше проверить после первого запуска.
