STEP 22.2 — Shulker move fix

Что исправлено:
1. Шалкер больше не закрывается сразу, если сервер открыл окно с кастомным/неожиданным названием.
2. Убрана жесткая блокировка по слову "храни" в названии окна. Раньше из-за этого мод мог открыть шалкер и сразу закрыть его, не перекладывая ресурсы.
3. Добавлено ожидание открытия/синхронизации слотов шалкера до 1500ms с повторной проверкой каждые 100ms.
4. SHULKER_OPEN_WAIT_MS увеличен с 300ms до 450ms.
5. SHULKER_AFTER_MOVE_WAIT_MS увеличен с 150ms до 200ms.

Ожидаемая логика:
полный инвентарь -> закрыть /ah -> выбрать шалкер из хотбара -> открыть -> проверить свободные слоты -> переложить до 9 предметов -> закрыть -> вернуть /ah.

Команды для проверки:
.mab shulker scan
.mab shulker test
.mab shulker status

Если снова не переложит, нужен latest.log со строками [MAB] shulker или вывод .mab shulker status.
