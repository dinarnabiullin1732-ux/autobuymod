Step 19.9 — FullAuto по времени, без лимитов циклов

Что изменено:
1. FullAuto больше не работает по количеству циклов/покупок.
2. Теперь один раунд FullAuto:
   - открывает /ah;
   - 90 секунд обновляет аукцион и покупает подходящие предметы;
   - после 90 секунд переходит в хранилище;
   - забирает предметы из хранилища;
   - продает предметы до сообщения лимита /ah rent или пока не закончатся подходящие предметы;
   - возвращается в /ah;
   - повторяет следующий 90-секундный раунд, пока FullAuto не остановлен.
3. Бинд R по-прежнему запускает/останавливает FullAuto даже при открытом аукционе.
4. Добавлен sell-until-rent режим:
   - внутренне используется FullAuto;
   - вручную можно проверить командой .mab sellloop 0 300
   - 0 означает продавать без max-счетчика, пока не будет /ah rent или не закончатся подходящие предметы.
5. Smart reopen после зависания аукциона сохранен.
6. Хранилище и пропуск последней строки хранилища сохранены.

Главные тайминги:
- покупка+обновление FullAuto: 90 секунд
- refresh/update: 300ms
- sell delay: 300ms
- storage open/take: 300ms
- return /ah: 3000ms

Проверка:
.mab fullauto
или нажать R

Debug:
.mab debug
Смотри строки:
- fullAutoTimed
- limitedLoopTimeMode
- limitedLoopTimeLeftMs
- cycleFull
- sellerLoop
