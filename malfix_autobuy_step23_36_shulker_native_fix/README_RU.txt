Malfix AutoBuy Step 4 CMD Ready

Эта версия уже запускается как клиентский Fabric-мод и подключает runtime/debug слой.

Что умеет Step 4:
- подключается к client tick через Mixin;
- ловит локальные команды из чата;
- читает открытый экран аукциона;
- считает fingerprint слотов;
- вручную сканирует текущую страницу аукциона;
- показывает лучший найденный слот, цену и цену за штуку.

Важно:
- эта версия НЕ покупает предметы;
- BuyExecutor пока специально не подключен;
- Fabric API пока не нужен;
- NeverAPI пока не нужен.

Как собрать:
1. Распакуй архив в простую папку, например:
   C:\MalfixAutoBuyStep4

2. Запусти:
   00_SET_JAVA21_AND_BUILD.cmd

Если твоя Java 21 стоит не тут:
   C:\Program Files\Java\jdk-21
открой 00_SET_JAVA21_AND_BUILD.cmd и поменяй путь JAVA_HOME.

После успешной сборки jar будет тут:
   build\libs

В mods кидай обычный jar без слова sources.

Команды в игре:
.mab help   - список команд
.mab open   - отправить /ah
.mab fp     - проверить открыт ли аукцион и fingerprint
.mab scan   - один раз просканировать текущий аукцион
.mab debug  - состояние ядра
.mab on     - включить scan/debug loop, без покупки
.mab off    - выключить

Рекомендуемый тест:
1. Запусти Minecraft.
2. Зайди на тестовый сервер/мир.
3. Напиши .mab help
4. Открой /ah.
5. Напиши .mab fp
6. Напиши .mab scan

Если .mab scan не находит предметы, это не обязательно баг: в текущих целях стоят только:
- Талисман крушителя
- Талисман карателя
- Талисман ярости
- Сфера титана
