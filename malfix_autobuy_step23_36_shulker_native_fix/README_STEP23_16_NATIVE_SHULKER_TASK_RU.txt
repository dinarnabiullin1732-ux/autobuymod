Step23.16 — shalk.js task native fallback

Что изменено:
- задача shalk.js (полный инвентарь -> закрыть /ah -> открыть шалкер из хотбара -> переложить предметы -> вернуть /ah) теперь выполняется нативным ShulkerController, а не зависит только от старого Never/SpookyBuy JS.
- старый JS больше не тикает параллельно, пока нативный shulker-controller работает.
- автоматический native restack включён обратно для фазы автобая.
- сообщение "полный инвентарь" сначала пробует запустить native restack; если native не смог стартовать, сообщение уходит в JS как fallback.

Важно:
- шалкер должен лежать в хотбаре (0-8), как и в оригинальном shalk.js.
- проверить состояние можно командой: .mab shulker status
- принудительный тест: .mab shulker test
