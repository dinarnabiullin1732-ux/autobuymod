Step23.11 script menu hard guard

Исправление для shalk.js: старые Never/Spooky скрипты больше не могут закрывать каждое открытое меню.

Что изменено:
- JS tick не выполняется, если игрок открыл пользовательское меню/инвентарь/настройки/неизвестный серверный GUI.
- closeCurrentScreen из скрипта теперь закрывает только узко распознанные окна: шалкер, эндер-сундук или аукцион.
- GenericContainerScreen больше не считается автоматически "экраном скрипта", потому что многие серверные меню тоже generic и из-за этого закрывались каждый tick.
- resume после SpookyBuy.setState(true) теперь отменяется, если открыт не принадлежащий скрипту GUI.

После обновления обязательно выполнить .mab scripts reload или перезапустить клиент.
