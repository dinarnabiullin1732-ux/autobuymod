Malfix AutoBuy Step 17.6 — Return to auction after sell limit

Добавлено:
После сообщения лимита продажи seller теперь не просто останавливается, а возвращает игрока к аукциону.

Логика:
1. Сервер пишет лимит продажи / /ah rent / rent slots.
2. Seller-loop останавливается.
3. Мод ждёт 700ms.
4. Если открыт GUI — закрывает его.
5. Через короткую задержку отправляет:
   /ah
6. Продажу дальше не продолжает.

Важно:
- sellloop НЕ перезапускается сам.
- Покупка/автобай НЕ включается силой.
- Это только аккуратный возврат в окно аукциона после лимита продажи.
- Если в этот момент активен autobuy/loop/buy action, возврат отменяется.

Debug:
.mab debug теперь показывает:
sellerReturnToAuction=pending/delay/attempts/reason
