Step 19.3 — storage last row skip fix

Что исправлено:
- В окне хранилища последняя строка верхнего контейнера больше не считается предметами хранилища.
- При заборе предметов из хранилища QUICK_MOVE кликает только реальные строки с предметами.
- Последняя строка с кнопками/навигацией типа меч, звезда, часы, верстак/сундук пропускается.
- Лог storage relist теперь пишет controlRowSkipped=true.

Проверка:
.mab storagecycle 36 10 900

Ожидаемо:
- Забирает предметы только из верхних строк хранилища.
- Не кликает последнюю строку с управляющими кнопками.
- После этого закрывает хранилище и запускает sellcycle.
