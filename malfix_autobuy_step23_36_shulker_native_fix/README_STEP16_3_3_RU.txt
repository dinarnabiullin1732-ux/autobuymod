Malfix AutoBuy Step 16.3.3 — generated-style GUI + /ah search button

Что изменено:
1. GUI сделан меньше и ближе к сгенерированному макету.
2. Убраны нижние кнопки/лишние элементы. Закрытие — Esc.
3. Кнопка /ah больше НЕ включает/выключает предмет.
4. Кнопка /ah теперь закрывает GUI и отправляет в чат:
   /ah search <название предмета>
5. Поиск берёт название выбранного предмета из GUI.
6. Правило безопасности не менялось: если цена покупки 0, предмет не покупается.

Важно:
- Команда отправляется без кавычек, чтобы серверный поиск не искал символы кавычек.
- Цена 0 по умолчанию означает: не покупать.
