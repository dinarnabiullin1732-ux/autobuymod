Step 23.31 — Telegram only buy/sold + no suggestions

Изменения:
1. Полностью отключены подсказки команд после ввода точки.
   ChatScreenMixin больше не подключается в malfix_autobuy.mixins.json.

2. Telegram больше не пишет о выставлении предмета на продажу.
   Подтверждения вида "выставлено на продажу" используются только для внутреннего seller-loop.

3. Telegram пишет только фактические сделки:
   - купил предмет;
   - продал предмет.

4. Из Telegram-сообщений покупки/продажи убрана строка "Источник".

5. В сообщениях покупки/продажи оставлены:
   - предмет;
   - кол-во;
   - цена;
   - цена за шт;
   - баланс.
